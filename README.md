## 1. プロジェクト概要

### 1.1 これは何？

**ISLA NUBLAR RESEARCH LAB — QUIZ EXPEDITION** は、文化祭の校内周遊型リアル謎解きゲーム用のタブレットWebアプリケーションです。

参加チームはタブレット1台を持ち、校内に設置された4つの調査区画（＋FINAL）を巡り、展示パネルやポスターを手がかりにクイズを解いていきます。正解するごとに「起動コード」の欠片を入手し、最終的にコードを連結してミッションを完了させるというストーリー仕立てのゲームです。

### 1.2 技術概要

- **動作環境**：タブレット（iPad / Android）のブラウザ（Safari / Chrome）
- **技術構成**：HTML + CSS + JavaScript のみ（完全クライアントサイド）
- **データ保存**：`localStorage`（端末内）に進行状況を保存
- **サーバー不要**：校内Wi-Fiが不安定でも動作（フォント読み込み時のみインターネット接続が必要）
- **QRコード共有**：完了結果をスマホに転送可能

### 1.3 ストーリー（コンセプト）

あなたたちは「イスラ・ヌブラル研究所」の特別調査チーム。校内に点在する4つの展示エリア（区画）を巡り、脱走した恐竜の特定とセキュリティコードの解読を命じられた。全区画の謎を解き、最終起動コードを入力して施設のロックダウンを解除せよ！

## 3. 機能一覧

### 3.1 チーム登録画面
- チーム名入力（最大20文字）
- ストーリーコンセプトの事前確認
- 「ミッション開始」ボタンでフルスクリーン起動＋ゲーム開始

### 3.2 ダッシュボード画面
- **調査指示書パネル**：現在の区画のストーリーと移動先を表示
- **ステータスパネル**：調査済み区画数（0/4）、レーダーアニメーション、入手した手がかり一覧
- **区画カード一覧**：5枚（一区画〜四区画＋FINAL）。状態は「調査中（緑発光）」「クリア」「未解放」で表示
- **アクションバー**：「前の区画」「クイズに挑戦」「次の区画」

### 3.3 進行ロジック（順次解放）
- **一区画 → 二区画 → 三区画 → 四区画 → FINAL** の順に強制的に解放
- 現在の区画に正解しない限り次の区画には進めない
- クリア済み区画は「解説を見る」で復習可能

### 3.4 クイズ機能
- 各区画ごとに複数パターン（A, B, ...）を用意
- チーム登録時にランダムで1パターンを抽選 → チームに固定
- 2回間違えるとヒントが表示される
- 正解すると「起動コードの欠片」を入手

### 3.5 スコアリング（タイムアタック）
- **所要時間に応じてポイントを自動計算**
  - 3分未満：30,000pt
  - 5分未満：25,000pt
  - 7分未満：20,000pt
  - 10分未満：15,000pt
  - 15分未満：10,000pt
  - 15分以上：5,000pt

### 3.6 完了画面（結果表示）
- チーム名・スコア・起動コード・日付・ゲーム名を表示
- **「🎉 CONGRATULATIONS!」** の祝福メッセージ
- **2種類のQRコード**：
  ① 結果ページURL（スマホでスキャン → 同じ結果を表示）
  ② 恐竜コラムURL（豆知識ページへ）
- **「結果を画像で保存」ボタン**：記念画像をPNGでダウンロード（QRコード付き）

### 3.7 恐竜コラム（別ページ）
- ゲームに登場する恐竜5種の豆知識（トリビア）を掲載
- 完了画面のQRコードからスマホでアクセス可能
- クイズとは独立したURL（`dino-column.html`）

### 3.8 管理者（ADMIN）機能
- 画面右下に常時表示される `⚙️ ADMIN` ボタン
- パスコード認証（デフォルト：`admin`）
- **ロック解除**：セキュリティ違反でロックされた端末を復帰
- **端末初期化**：次のチーム用にデータを全消去

### 3.9 セキュリティ機能
- フルスクリーン強制
- タブ・アプリ切り替え検知
- フルスクリーン解除検知
- 右クリック・コピー・カット禁止
- 開発者ツールショートカットブロック
- 違反時は緊急ロック画面に移行

## 4. 問題・指示書の編集方法（非エンジニア向け）

### 4.1 編集するファイル
`quiz.js` をテキストエディタ（メモ帳・Visual Studio Codeなど）で開きます。

### 4.2 どこを編集するか
`quiz.js` の中の **`SECTOR_POOLS`** という配列が、全区画の問題データです。

```javascript
const SECTOR_POOLS = [
  {
    id: 0,                // 区画ID（0〜3、変更不要）
    name: '一区画',       // 区画名（変更可）
    shortName: '一区画',  // カードに表示される短い名前（変更可）
    areaName: 'JUNGLE AREA', // エリア名（変更可）
    icon: '🦖',           // アイコン（絵文字可）
    location: '1階 101教室前「ジャングル・パドック」', // ★ 移動先を記載
    instructions:         // ★ 調査指示書（ストーリー）
      '【CHAPTER 1 - JUNGLE AREA】\n' +
      '監視ドローンからの通信が途絶えた。まず 1階 101教室前 の「ジャングル・パドック」展示エリアへ向かえ。\n' +
      '...',
    patterns: [           // ★ 出題パターン（A, B, ...）
      {
        patternName: 'A',
        title: '一区画：ジャングルエリア (Pattern A)',
        question:          // ★ 問題文
          'パドックの記録には「体長20m級。小さな頭部と長い首を持つ、竜脚類の中でも屈指の大きさを誇る草食竜」と記されている。\n' +
          'この恐竜の名前を英語（アルファベット）で入力せよ。',
        answers: ['BRACHIOSAURUS', 'ブラキオサウルス'], // ★ 正解（複数可）
        hint: 'ヒント：首がとても長く、キリンのように高い木の葉を食べる巨大な竜脚類だ。', // ★ ヒント
        explanation: '正解は「ブラキオサウルス」。...', // ★ 解説
        clueCode: 'J7',    // ★ 正解時に入手する起動コード欠片
      },
      // パターンB, C... を追加可能
    ],
  },
  // 二区画、三区画、四区画も同様
];
```

### 4.3 各区画の編集ポイント

| 項目 | 説明 | 例 |
|------|------|-----|
| `location` | 生徒が実際に移動する校内の場所 | `'1階 101教室前「ジャングル・パドック」'` |
| `instructions` | 調査指示書のストーリー本文（`\n` で改行） | `'【CHAPTER 1】\n監視ドローンからの通信が途絶えた...'` |
| `question` | クイズの問題文（`\n` で改行可） | `'この恐竜の名前を英語で入力せよ。'` |
| `answers` | 正解として許容する表記（複数追加可） | `['BRACHIOSAURUS', 'ブラキオサウルス', 'brachiosaurus']` |
| `hint` | 2回間違えた時に表示されるヒント | `'ヒント：首がとても長い...'` |
| `explanation` | 正解後に表示される解説 | `'正解は「ブラキオサウルス」。...'` |
| `clueCode` | 正解で入手するコード欠片（FINALで使用） | `'J7'`（2〜3文字推奨） |

### 4.4 パターンを追加する方法

各区画の `patterns` 配列に、新しいオブジェクトを追加します。

```javascript
patterns: [
  {
    patternName: 'A',
    // ... パターンAのデータ
  },
  {
    patternName: 'B',
    // ... パターンBのデータ
  },
  {
    patternName: 'C',  // ★ 新しくパターンCを追加
    title: '一区画：ジャングルエリア (Pattern C)',
    question: '新しく追加した問題文...',
    answers: ['答え1', '答え2'],
    hint: 'ヒント...',
    explanation: '解説...',
    clueCode: 'X1',
  },
],
```

**注意**：パターンを追加しても、チーム登録時にランダムで1つ選ばれるだけなので、問題数が増えてもゲームの流れは変わりません。

### 4.5 FINAL区画の編集

`FINAL_SECTOR` オブジェクトで編集します。

```javascript
const FINAL_SECTOR = {
  id: 'final',
  name: 'FINAL',
  shortName: 'FINAL',
  areaName: 'CONTROL CENTER',
  icon: '🚨',
  location: '体育館ステージ前「メインコントロールセンター」', // ★ 集合場所
  instructions:  // ★ FINALの指示書
    '【FINAL CHAPTER - CONTROL CENTER】\n' +
    '全区画の調査、お疲れさまでした。体育館ステージ前 の「メインコントロールセンター」に集合せよ。\n' +
    'これまで入手した4つの起動コード欠片を、調査した順番のまま連結して入力し、施設の緊急ロックダウンを解除せよ。',
};
```

### 4.6 起動コードの連結ルール

- 各区画で入手した `clueCode` を **調査した順番** に連結したものが最終コード
- 例：一区画で `J7`、二区画で `R9`、三区画で `A2`、四区画で `L8` を入手 → 最終コードは `J7R9A2L8`
- 大文字/小文字は区別しない（自動で正規化）

## 5. 管理者（ADMIN）機能

### 5.1 操作方法

1. 画面右下の **`⚙️ ADMIN`** ボタンをタップ
2. パスコードを入力（デフォルト：`admin`）
3. 以下の操作が可能に：

| ボタン | 機能 | 使用シーン |
|--------|------|------------|
| **ロック解除（再開）** | 緊急ロックを解除し、ゲームを再開 | 生徒が誤ってタブを切り替えてロックされた時 |
| **端末初期化（次のチームへ）** | 全データを削除し登録画面に戻る | チーム交代時 |

### 5.2 パスコードを変更する方法

`quiz.js` の先頭にある `CONFIG.ADMIN_PASSCODE` の値を変更します。

```javascript
const CONFIG = {
  STORAGE_KEY: 'jw_quiz_expedition_state_v1',
  ADMIN_PASSCODE: 'admin', // ★ ここを任意のパスワードに変更
  SECTOR_COUNT: 4,
  // ...
};
```

**重要**：パスコードは平文で保存されるため、完全なセキュリティは保証されません。文化祭イベント内の「うっかり防止」としてご利用ください。

## 6. QRコード機能（スマホで結果を共有）

### 6.1 仕組み

完了画面に表示されるQRコードには、**チーム名・スコア・日付・ゲーム名・コード一覧** を短縮したURLパラメータとして埋め込んでいます。

**URL例（約100文字）**：
```
https://example.com/index.html?t=ラプトル探検隊&s=25000&d=20260828&g=ISLA+NUBLAR+RESEARCH+LAB&c=J7,R9,A2,L8
```

### 6.2 スマホでの使い方

1. タブレットの完了画面で **「結果ページURL」QRコード** を表示
2. スマホのカメラでQRコードをスキャン
3. スマホのブラウザで同じ完了画面が開く
4. 「結果を画像で保存」ボタンをタップ → スマホに記念画像を保存

### 6.3 QRコードの種類

| QRコード | リンク先 | 用途 |
|----------|----------|------|
| **結果ページURL** | `index.html?t=...&s=...` | スマホで結果を表示・画像を保存 |
| **恐竜コラム** | `dino-column.html` | 登場恐竜の豆知識を読む |

### 6.4 ダウンロード画像に含まれる内容

- 🎉 CONGRATULATIONS!（祝福メッセージ）
- ゲーム名
- 日付
- チーム名
- スコア（ポイント）
- 所要時間
- 起動コード
- 恐竜コラムへのQRコード
- `supported by`（協賛・実行委員会名）

## 7. セキュリティ機能と限界

### 7.1 実装されている機能

| 機能 | 内容 |
|------|------|
| フルスクリーン化 | チーム登録時に自動で全画面表示 |
| タブ切り替え検知 | Page Visibility API で検知 → 緊急ロック |
| フルスクリーン解除検知 | `fullscreenchange` イベントで検知 → 緊急ロック |
| 右クリック禁止 | `contextmenu` イベントを無効化 |
| コピー/カット禁止 | `copy` / `cut` イベントを無効化 |
| 開発者ツール禁止 | F12・Ctrl+Shift+I等をブロック |
| 緊急ロック画面 | 違反時に操作不能なロック画面を表示 |
| ADMINによる解除 | スタッフがロックを解除可能 |

### 7.2 限界と注意事項

⚠️ **これらの機能は「うっかり不正」や「その場のノリでのズル」を抑止するためのものであり、悪意のある技術的攻撃を完全に防ぐことはできません。**

- **問題と回答はクライアントサイドに平文で含まれている**  
  → ブラウザの「ページのソースを表示」で誰でも答えを読めます。
- **ADMINパスコードも平文でJSファイルに記述**  
  → デフォルト値から変更することを強く推奨します。
- **localStorageは開発者ツールから自由に書き換え可能**  
  → 進行データの改ざんが可能です。

これらの制限は、本アプリが「文化祭というクローズドな環境でカジュアルなゲームを運用する」ことを前提としているためです。  
**本気の競技として実施する場合は、サーバーサイドで答えや進捗を管理する方式への移行を検討してください。**

### 7.3 誤爆防止対策

- ソフトウェアキーボードの開閉は `document.hidden` を変化させないため誤ロックしません。
- iOS Safariのフルスクリーン非対応環境でもエラーで停止しません（フォールバック処理あり）。

| 問題が間違っている | ADMINで初期化後、`quiz.js` を修正して再配布 |
| QRコードが読み取れない | 画面の明るさを最大にして再試行、または手動でURLを入力 |

## 9. カスタマイズ設定一覧

`quiz.js` の先頭にある `CONFIG` オブジェクトで、ゲーム全体の設定を変更できます。

```javascript
const CONFIG = {
  STORAGE_KEY: 'jw_quiz_expedition_state_v1', // 保存キー（変更不要）
  ADMIN_PASSCODE: 'admin',   // ★ 管理者パスワード

  SUPPORTED_BY: '文化祭実行委員会', // ★ 協賛・運営団体名（空文字で非表示）
};
```

### カスタマイズ可能な項目

| 設定項目 | 説明 | デフォルト値 |
|----------|------|--------------|
| `ADMIN_PASSCODE` | 管理者パスワード | `'admin'` |
| `GAME_NAME` | ゲームの正式名称 | `'ISLA NUBLAR RESEARCH LAB'` |
| `SUPPORTED_BY` | 協賛・実行委員会名 | `'文化祭実行委員会'`（空文字で非表示） |

ctx.fillStyle = '#f59e0b';    // ★ CONGRATULATIONS!の色

## 10. トラブルシューティング

### Q1. QRコードが読み取れない

**原因と対策**：
- 画面の明るさが足りない → 明るさを最大にする
- QRコードが小さすぎる → タブレットの画面を拡大表示する
- URLが長すぎる → 短縮URL版では約100文字なので問題なし
- カメラのフォーカスが合っていない → スマホのカメラを安定させる

### Q2. 問題を編集したのに反映されない

**原因と対策**：
- ブラウザのキャッシュが残っている → ページを強制リロード（Ctrl+F5）
- `quiz.js` の構文エラー → ブラウザの開発者ツール（F12）のコンソールでエラーを確認

### Q3. フルスクリーンにならない

**原因と対策**：
- iOS Safari は一部フルスクリーンAPIに対応していない → エラーにならずに通常表示で動作（フォールバック処理済み）
- ブラウザの設定で許可されていない → 設定を確認

### Q4. ロックが解除できない

**原因と対策**：
- ADMINパスコードが間違っている → `quiz.js` の `ADMIN_PASSCODE` の値を確認
- ADMINボタンが押せない（ロック画面が最前面） → ロック画面を透過設定済みなので、ボタンをタップすれば押せます

### Q5. 画像がダウンロードできない

**原因と対策**：
- ストレージの空き容量不足 → 不要なファイルを削除
- ブラウザのポップアップブロック → 許可する
- キャンバスデータの生成に失敗 → ブラウザを再起動

### Q6. localStrageのデータをクリアしたい

**方法**：
- 開発者ツール（F12）→ アプリケーション → ローカルストレージ → 該当キーを削除
- または ADMIN →「端末初期化」を実行

## 11. 拡張アイデア

### 11.1 既存の機能で実現可能なこと

- **区画数を増やす**：`CONFIG.SECTOR_COUNT` を変更し、`SECTOR_POOLS` に区画を追加
- **問題パターンを増やす**：各区画の `patterns` 配列に追加（問題のバリエーションが増える）
- **スコア基準を調整**：`calculateScore()` 関数の秒数とポイントを変更
- **支持団体名を変更**：`CONFIG.SUPPORTED_BY` を編集

### 11.2 サーバー導入時の拡張アイデア

| 拡張アイデア | 概要 | 実装難易度 |
|--------------|------|------------|
| 全チームの進捗ダッシュボード | スタッフ用に全チームの状況をリアルタイム表示 | 中 |
| チームごとのタイムランキング | サーバーにスコアを集計しランキングを表示 | 中 |
| QRコードでチェックイン | 各区画にQRコードを設置し、到着確認 | 低 |
| 管理者ページのリモート操作 | 全端末を一括で初期化・ロック解除 | 高 |
| 答えをサーバーで管理 | 問題と回答をサーバーに置き、ソース閲覧対策 | 高 |
