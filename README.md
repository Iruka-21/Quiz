# 🦖 ISLA NUBLAR RESEARCH LAB — QUIZ EXPEDITION

文化祭・校内周遊型リアル謎解きゲーム用のタブレット向けWebアプリケーションです。
ジュラシック・ワールドの研究施設をテーマに、チームごとにタブレット端末を1台使い、
校内4区画（＋FINAL）を巡って謎を解いていきます。

---

## 1. プロジェクト概要

- **用途**：文化祭の校内周遊型リアル謎解きゲーム
- **運用形態**：参加チームごとにタブレット端末（iPad / Android）を1台支給し、校内を巡らせる
- **テーマ**：ジュラシック・ワールドの研究施設（ISLA NUBLAR RESEARCH LAB / QUIZ EXPEDITION）
- **技術構成**：HTML / CSS / JavaScript のみで動作する完全クライアントサイドの静的サイト
  （サーバー・データベースへの通信は行いません。進行状況は端末の `localStorage` に保存されます）

## 3. 画面構成・機能一覧

### 3.1 チーム登録画面
- チーム名を入力して「ミッション開始」を押すと、
  - フルスクリーン化（対応端末のみ。iOS Safari等の非対応環境でもエラーで停止しない安全設計）
  - 各区画のランダム出題パターンを1問ずつ抽選・固定
  - セキュリティ監視（タブ離脱検知等）を起動
  - ダッシュボード画面へ遷移

### 3.2 ダッシュボード画面
- **最上部バー**：`TEAM: 〇〇` 表示、「📖 遊び方」「❓ 注意事項」モーダルボタン
- **中央 指示書パネル（MISSION BRIEFING）**：六角形風の緑発光フレームで、現在表示中区画のストーリー・移動先を表示
- **右上 STATUSパネル**：調査済み区画数（0/4）、CSSで回転するレーダーアニメーション、発見済み手がかり一覧
- **下部 区画カード一覧**：一区画〜四区画＋FINALの5枚。「調査中（緑発光）」「クリア（✓）」「未解放（🔒）」の状態表示
- **最下部アクションバー**：「◀ 前の区画」「クイズに挑戦する ➔」「次の区画 ▶」

### 3.3 進行ロジック（厳格な順次解放）
- 一区画 → 二区画 → 三区画 → 四区画 → FINAL の順に**強制的に解放**
- 現在挑戦中の区画に正解しない限り、次の区画には進めません（カード・ボタンともに操作不能）
- クリア済み区画は「解説を見る」として再訪問・振り返りが可能

### 3.4 問題プール・ランダム出題
- `quiz.js` の `SECTOR_POOLS` に、各区画ごと複数パターン（A, B, ...）を登録
- チーム登録時に区画ごとランダムで1パターンを抽選し、以後そのチームに固定
- チーム間で異なる問題になるため、答えを見せ合うカンニングを防止

### 3.5 入力ゆらぎの自動吸収
- 全角/半角、大文字/小文字、前後・中間の空白、中点・ハイフンなどの表記差を正規化して判定
- 正解バリエーションは `answers` 配列に自由に追加可能

### 3.6 進行データの保存
- `localStorage`（キー：`jw_quiz_expedition_state_v1`）にチーム名・クリア状況・手がかり・ロック状態を保存
- ブラウザの誤リロードでもデータは消えず、再読み込み時は「調査を再開しますか？」の復帰オーバーレイを表示

## 4. セキュリティ・不正防止機能

| 機能 | 内容 |
|---|---|
| 全画面化 | チーム登録完了時に Fullscreen API で自動フルスクリーン化。非対応環境でも処理停止しないフォールバック付き |
| 離脱検知 | Page Visibility API でタブ切替・アプリ切替（`document.hidden`）を検知 |
| フルスクリーン解除検知 | `fullscreenchange` イベントで解除を検知 |
| 右クリック禁止 | `contextmenu` イベントを無効化 |
| コピー/カット禁止 | `copy` / `cut` イベントを無効化 |
| 開発者ツール等の禁止 | F12、Ctrl+Shift+I/J/C/K、Ctrl+U、Ctrl+S、Ctrl+P 等をブロック |
| 🚨 緊急ロック画面 | 違反検知時に画面全体を「SECURITY VIOLATION」表示で操作不能にロック（**ただしADMINボタンは常時クリック可能**） |
| 誤爆防止 | ソフトウェアキーボードの開閉やアドレスバー操作は `document.hidden` を変化させないため誤ロックしない設計 |

**⚠️ 重要な注意**：これらはあくまでクライアントサイド（ブラウザ内）の検知・抑止機能であり、
完全なセキュリティ保証ではありません（例：OS標準の画面分割機能や外部デバイスでの記録などは技術的に検知できません）。
文化祭イベントにおける「一般的な不正の抑止」を目的とした仕組みとしてご利用ください。

## 5. 管理者（ADMIN）機能

- 画面右下に半透明の `⚙️ ADMIN` ボタンを**常時固定表示**（**緊急ロック画面が最前面でもクリック可能**）
- デフォルトパスコード：`CHANGE_ME` ← **必ず変更してください**
  - 変更方法：`quiz.js` 内 `CONFIG.ADMIN_PASSCODE` の値を編集します。
- **ロック解除（再開）**：誤操作でロックされた生徒をその場から即復帰
- **端末初期化（次へ）**：現在のチームのデータを全消去し、次のチーム用の登録画面に戻す

## 6. 問題・指示書の編集方法（制作担当者向け）

`quiz.js` の `SECTOR_POOLS` 配列を編集することで、問題・指示書を追加・変更できます。

```javascript
const SECTOR_POOLS = [
  {
    id: 0,                       // 区画ID（0〜3）
    name: '一区画',             // 正式名称（表示に使わないが管理用）
    shortName: '一区画',        // カードや手がかり一覧に表示される短い名前
    areaName: 'JUNGLE AREA',    // エリア名（カード内に表示）
    icon: '🦖',                 // アイコン（絵文字）
    location: '1階 101教室前「ジャングル・パドック」',  // 校内での移動先（生徒が読む）
    instructions:
      '【CHAPTER 1 - JUNGLE AREA】\n' +
      '監視ドローンからの通信が途絶えた。まず 1階 101教室前 の「ジャングル・パドック」展示エリアへ向かえ。\n' +
      '...',   // 指示書本文（\n で改行）
    patterns: [
      {
        patternName: 'A',        // パターン識別名（A, B, C...）
        title: '一区画：ジャングルエリア (Pattern A)',   // モーダルタイトル
        question:
          'パドックの記録には「体長20m級。小さな頭部と長い首を持つ、竜脚類の中でも屈指の大きさを誇る草食竜」と記されている。\n' +
          'この恐竜の名前を英語（アルファベット）で入力せよ。',
        answers: ['BRACHIOSAURUS', 'ブラキオサウルス'],   // 正解バリエーション（複数可）
        hint: 'ヒント：首がとても長く、キリンのように高い木の葉を食べる巨大な竜脚類だ。',
        explanation: '正解は「ブラキオサウルス」。...',   // 解説
        clueCode: 'J7',        // 正解時に入手する起動コード欠片（FINALで使用）
      },
      // パターンB, C... を追加可能
    ],
  },
  // 二区画、三区画、四区画も同様の構造
];
```
answers には全角/半角・大文字小文字などを気にせず複数の表記ゆらぎを追加できます（自動で正規化されます）

clueCode は各区画クリアで手に入る「起動コード」の欠片。FINAL区画で全区画分を調査した順につなげて入力するとゲームクリアになります

FINAL_SECTOR オブジェクトでFINALの指示書文言・集合場所を編集できます

7. 動作環境・利用方法
本サイトはビルド不要の静的HTML/CSS/JSです。index.html を開くだけで動作します

タブレット（iPad / Android）のブラウザ全画面表示での利用を想定してレイアウト・操作性を最適化しています

想定ブラウザ：Safari（iOS）、Chrome（Android）

ネットワーク環境：サーバー通信を行わないため、校内Wi-Fiの有無に依存しません（フォント・アイコンCDNの読み込みのみインターネット接続が必要です）

運用フロー（1チームあたり）
スタッフが端末を渡す前に、必要であれば ADMIN → 「端末初期化」で前チームのデータをクリア

チームがチーム名を入力して「ミッション開始」

校内を周遊し、各区画の指示書に従って謎を解く

全4区画クリア後、FINALで起動コードを入力してミッションコンプリート

完了画面をスタッフに提示 → 端末を回収し、ADMINで初期化して次のチームへ

10. データ構造・保存先
保存先：ブラウザの localStorage（キー：jw_quiz_expedition_state_v1）

保存内容：

```json
{
  "teamName": "チーム名",
  "createdAt": 1234567890,
  "selectedPatterns": [0, 1, 0, 1],
  "clearedSectors": 2,
  "clues": [{ "sectorName": "一区画", "code": "J7" }],
  "wrongAttempts": [0, 0, 0, 0],
  "finalCleared": false,
  "completedAt": null,
  "locked": false,
  "lockReason": ""
}
```
サーバーサイドのデータベースは使用していません（オフラインでも進行状況が保持されます）

11. セキュリティ機能の限界と注意事項（文化祭運営者向け）
本アプリのセキュリティ機能は「うっかり不正」や「その場のノリでのズル」を抑止するためのものであり、悪意のある技術的攻撃を完全に防ぐことはできません。

問題と回答はすべてクライアントサイド（ブラウザ）に平文で含まれています。

ブラウザの「ページのソースを表示」や view-source: で誰でも答えを読むことができます。

ADMINパスコードも同様にJSファイル内に平文で記述されています。

本番公開前には必ずデフォルト値（CHANGE_ME）を変更してください。

localStorage はブラウザの開発者ツールから自由に書き換え可能です。

localStorage.setItem('jw_quiz_expedition_state_v1', '...') で進行データを改ざんできます。

これらの制限は、本アプリが「文化祭というクローズドな環境で、カジュアルなゲームを運用する」ことを前提としているためです。
もし「本気の競技」として実施する場合は、サーバーサイドで答えや進捗を管理する方式への移行を検討してください。
