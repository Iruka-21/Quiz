# 🦖 JURASSIC WORLD: RESEARCH FACILITY 調査システム

文化祭のリアル体験型・周遊謎解きゲーム用Webアプリケーションです。  
タブレットを各チームに支給して会場内（4区画＋FINAL）を巡る運用に最適化されています。

---

## 📁 ファイル構成
- `index.html` : サイトの基本構造
- `style.css` : ジュラシック風ダークテーマ・タブレット最適化デザイン
- `quiz.js` : **問題データ** および ゲーム進行システム制御スクリプト
- `README.md` : 取扱説明書（本ファイル）

---

## 🟩 問題・答えの編集方法
問題や解答の変更は **`quiz.js` の最上部にある `SECTORS` 配列** を編集するだけです。

```javascript
{
    id: 0,
    name: "第1区画",
    shortName: "第1区画",
    title: "第1区画：草食恐竜エリア (HERBIVORE)",
    location: "【移動先】1階 101教室前へ向かってください", // 移動先案内
    question: "【調査ミッション 01】\nここに問題文を書きます。",
    answers: ["BRAK", "brak", "ブラキオ"], // 正解（複数登録可）
    hint: "ここにヒントを書きます。",
    explanation: "クリア後に表示される解説を書きます。"
}
