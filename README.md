# 🦖 JURASSIC WORLD: RESEARCH FACILITY 調査端末システム
## （Google Forms ロックモード完全対応版）

文化祭の周遊謎解き企画向けに開発された、タブレット専用の不正防止・調査進行Webシステムです。

---

## 📁 ファイル構成
```text
├── index.html   # 端末UI、ロック画面、管理者モーダル
├── style.css    # ジュラシック風ダークテーマ & セキュリティUI
├── quiz.js      # 問題データ & ロックモード制御ロジック
└── README.md    # 説明書
```
## 🔐 管理者（スタッフ）用パスコード
パスコード: admin
解除できる機能:
緊急ロックの解除（調査再開）: 誤って通知等をタップしてロックされた生徒の復帰用。
端末の初期化（次チームへ）: ゲーム終了時に最初の登録画面に戻す用。
※パスコードを変更する場合は quiz.js の ADMIN_PASSWORD を書き換えてください。
## 🛡️ 動作する不正防止機能
全画面表示（Fullscreen API） の強制
別タブ・別アプリへの切り替え検知（検知時に即ロック）
画面外タップ・通知タップの検知（検知時に即ロック）
右クリック・長押しメニュー・テキストコピーの完全無効化
F12・Ctrl+U などの開発者ショートカット禁止
