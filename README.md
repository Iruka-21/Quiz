# 🦖 ジュラシック・ワールド周遊謎解きタブレットシステム - 運用マニュアル

## 📋 概要

本システムは、文化祭の校内周遊型リアル謎解きゲーム用のWebアプリケーションです。
参加チームごとにタブレット端末を1台支給し、校内を巡りながら謎を解いていくスタイルで運用します。

### ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | UI構造・各モーダル・管理者ボタン・ロック画面 |
| `style.css` | 映画風ダークUI・レーダーアニメーション・タブレット最適化 |
| `quiz.js` | 指示書スペース・問題プール・進行制御・セキュリティ |
| `README.md` | 本マニュアル |

---

## 🚀 セットアップ手順

### 1. ファイルの配置

3つのファイル（`index.html`、`style.css`、`quiz.js`）を**同じディレクトリ**に配置してください。

### 2. サーバーの準備（推奨）

セキュリティ機能（Fullscreen APIなど）を正常に動作させるため、**ローカルサーバーでの配信を推奨**します。

#### 方法A: Pythonを使う場合
```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```
方法B: Node.jsを使う場合
```bash
npx serve .
```
方法C: 直接ファイルを開く場合
index.html をブラウザで直接開くことも可能ですが、一部の機能（Fullscreen APIなど）が制限される場合があります。

3. タブレット端末でのアクセス
同一ネットワーク上のタブレットから、http://[サーバーのIPアドレス]:8080 にアクセスします。

🎮 ゲーム進行フロー
チーム登録
初期画面でチーム名を入力

「🦖 探検開始」ボタンを押す

自動的にフルスクリーン化され、各区画の問題がランダムに抽選されます

区画調査
調査指示書を確認し、指定された校内の場所へ移動

現地で問題の答えを見つける

「クイズに挑戦する」ボタンから回答を入力

正解すると次の区画が解放されます

進行ロック
一区画 → 二区画 → 三区画 → 四区画 → FINAL の順に解放

前の区画をクリアしないと次の区画には進めません

チームごとに問題パターンが異なるため、カンニング防止になります

完了条件
全4区画＋FINALをクリアすると完了画面が表示されます

クリアコードをスタッフに提示してもらいます

🔧 問題の編集方法
問題データの構造
quiz.js の冒頭にある SECTOR_POOLS 配列を編集します。

javascript
const SECTOR_POOLS = [
    {
        id: 0,
        name: "一区画",
        shortName: "一区画",
        areaName: "JUNGLE AREA",
        icon: "🦖",
        instructions: "【一区画 調査指示書】...",
        patterns: [
            {
                patternName: "A",
                title: "一区画：ジャングルエリア (Pattern A)",
                question: "【問題文】...",
                answers: ["答え1", "答え2"],  // 複数正解を許容
                hint: "ヒント...",
                explanation: "解説..."
            },
            // パターンB、C...と追加可能
        ]
    },
    // 二区画、三区画、四区画、FINAL...
];
編集ポイント
項目	説明
name	区画の表示名
shortName	カードに表示する短い名前
areaName	英語表記（エリア名）
icon	区画カードに表示する絵文字
instructions	指示書パネルに表示される移動指示・ストーリー
patterns	問題パターンの配列（複数用意可能）
patternName	パターンの識別子（A, B, C...）
question	問題文（\n で改行可能）
answers	正解の配列（複数指定可能）
hint	ヒント（ボタンで表示）
explanation	正解時の解説
問題追加の注意点
パターン数：各区画に最低2パターン以上用意してください

答えの表記ゆれ：answers 配列に複数の正解を登録できます

例：["ブラキオサウルス", "ブラキオ"]

入力正規化：全角/半角、大文字/小文字は自動で正規化されます

指示書の内容：校内の具体的な場所を明記してください

👮 管理者機能
管理者ボタン
画面の右下に常時表示されている「⚙️ ADMIN」ボタンからアクセスします。

パスコード認証

管理者メニュー
機能	説明
🔓 ロック解除 (再開)	セキュリティロックされた端末を復帰させる
🔄 端末初期化 (次へ)	データを全消去し、次のチーム用に初期化する
パスコードの変更方法
quiz.js の以下の行を編集します：

javascript
const ADMIN_PASSWORD = "admin";
任意のパスコードに変更してください。

🆘 トラブルシューティング
Q: タブレットでフルスクリーンにならない
A: iOS SafariはFullscreen APIに一部非対応です。画面を縦向きにして、Safariの「ホーム画面に追加」から起動すると擬似フルスクリーンになります。

Q: セキュリティロックが頻繁に発生する
A: ソフトウェアキーボードの起動が誤検知される場合があります。タブレットの設定で「外付けキーボード」を使用するか、quiz.jsのlastVisibilityChangeの閾値（500ms）を調整してください。

Q: 問題の答えが正しく判定されない
A: answers配列に正しい答えが登録されているか確認してください。入力は自動で全角→半角、大文字→小文字の正規化が行われますが、カタカナの表記ゆれには対応していない場合があります。
