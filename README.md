## 📝 パートごとの指示書の書き込み方法
quiz.js の SECTOR_POOLS 内にある instructions の部分に自由に指示・ストーリー・移動先を書き込んでください。

{
    id: 0,
    name: "一区画",
    areaName: "JUNGLE AREA",
    // 📋 ここにパートごとの指示書を自由に記入してください
    instructions: "【一区画 調査指示書】\n1階 101教室前のジャングルパドックへ向かえ。\n現地の展示パネルを調査し、隠されたセキュリティコードを解読せよ。",
    patterns: [
        // 問題データ（複数パターン）
    ]
}

## 🔑 管理者（スタッフ）操作
画面右下の 「⚙️ ADMIN」 ボタンはどの画面でも常に固定表示されています。
パスコード: admin
「ロック解除 (再開)」 : 誤操作でロックされた生徒をその場で復帰。
「端末初期化 (次へ)」 : ゲーム終了時、次チーム貸出用に初期化。
