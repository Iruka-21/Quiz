# 🦖 JURASSIC WORLD: RESEARCH FACILITY 調査端末システム

文化祭のリアル体験型・周遊謎解きゲーム用Webアプリケーションです。  
タブレット支給時のイタズラ防止・テストロックモードを搭載しています。

---

## 📁 ファイル構成
- `index.html` : 端末UI構造 & 管理者モーダル
- `style.css` : ジュラシック風ダークテーマ & ロック画面UI
- `quiz.js` : 問題データ、システム制御、セキュリティロック制御
- `README.md` : 説明書

---

## 🔐 管理者用パスコード
- 解除パスコード: **`admin`**  
（※変更する場合は `quiz.js` の `ADMIN_PASSWORD` を書き換えてください）

---

## 🛡️ タブレット完全ロック運用のコツ（推奨）
本システム自体で全画面化・操作禁止を行いますが、端末の「ホームボタン」や「スワイプでブラウザを閉じる操作」まで完全に防ぐには、タブレット本体の以下の設定を併用してください。

- **iPad の場合**:  
  「設定」→「アクセシビリティ」→「アクセスガイド」をONにし、Safariを開いた状態で電源ボタンをトリプルクリック（3回押し）。
- **Android の場合**:  
  「設定」→「セキュリティ」→「アプリの固定（ピン留め）」をONにし、Chromeを開いて固定。

---

## 🟩 問題・答えの編集
`quiz.js` の最上部にある `SECTORS` 配列のテキストを書き換えるだけでOKです。
